# Event Booking System - Features & Requirements

This document outlines the complete list of features and functionalities required for the Event Booking System, categorized by user roles and system-wide requirements.

## 1. Admin
*   Approve venue owner and vendor accounts
*   Approve customer accounts
*   Manage event categories (wedding, birthday, corporate, seminar)
*   Set commission and cancellation rules
*   Monitor booking statistics
*   Generate monthly booking reports (PDF)
*   Broadcast seasonal offers and announcements

## 2. Venue Owners
*   Add venues with photos, capacity, and rates
*   Manage the availability calendar
*   Approve or reject booking requests
*   Offer packages (with catering, decoration, etc.)
*   Track advance and full payments (dummy)
*   Generate booking confirmations (PDF)
*   Chat with customers

## 3. Vendors (Caterers, Decorators, Photographers)
*   Create service profiles with portfolios
*   Set package prices
*   Accept or decline event service requests
*   Update service preparation status
*   Chat with customers

## 4. Customers
*   Create account and log in
*   Search venues by date, capacity, and budget
*   Book a venue and add vendor services
*   Pay advance (dummy transactions)
*   Track booking and vendor confirmation status
*   Rate venues and vendors after the event
*   Download booking invoices (PDF)
*   Chat with venue owners and vendors

## 5. Guests
*   Browse venues and vendor portfolios
*   See package prices and photo galleries
*   Access contact page

## 6. Other System-Wide Requirements
*   **Conflict Prevention**: Date-conflict prevention on the venue calendar must be included
*   **Reviews & Ratings**: Review and rating system should be included
*   **Communication**: Include a chat feature (real-time communication between customers and venue owners/vendors)
